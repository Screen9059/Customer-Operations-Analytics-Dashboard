# Customer-Operations-Analytics-Dashboard

# Personal Project:
This is my second personal project on my data analytics learning path. After completing two certifications with Coursera and Cisco, I want to put what I've learned into practice and start simulating projects to continue learning.
This time I wanted to focus on Excel, which, from my point of view, is a very common and basic tool that we use for various purposes such as lists, budgets, etc., but it also has a great capacity for analyzing data.
And finally, for the visualization and the dashboard, I will use Tableau.

# Objetive:
This project simulates a real SaaS customer support environment and builds an interactive operations dashboard using Excel. It analyzes 20 customer support tickets across multiple categories such as Login Issues, Mobile App Bugs, and Payment Problems.
The dataset is structured to reflect real operational data, including ticket volume, resolution performance, SLA compliance, and customer satisfaction (CSAT). Business logic is applied using Excel formulas and a binary CSAT flag to classify customer outcomes.
Pivot Tables are used to aggregate key metrics, while slicers enable dynamic filtering by dimensions such as subscription type, channel, and team. The dashboard tracks core KPIs including total tickets, SLA compliance rate, SLA breach rate, and CSAT percentage.
